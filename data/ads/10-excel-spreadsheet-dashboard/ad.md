I require an excel spreadsheet that can be used as a dashboard to generate weekly and monthly reports, based on information provided. The spreadsheet will consist of two sheets - the first one showing the dashboard, and the second where I can paste in some data exported from one of our systems. Each week, new data will be pasted to the bottom of sheet 2. The dashboard should automatically update to reflect the new data that has been entered.

The dashboard will consist of 5 sections:

- Profitable vs Not Profitable Pie Chart - A pie chart will be displayed showing the total number of cases that were profitable, and the total number that were not profitable.

- Financial Forecast Graph - A stacked graph showing the total amount of fees collected each month, plus the total amount of extras charged each month. A line graph displaying the current financial target should also be shown (configurable). Bar graphs should be cumulative (i.e reflect this months totals + the totals of the financial year so far)

- Cases By Mortgage Type - A table showing total cases grouped by mortgage type. Count, total and average should be displayed.

- Cases By Advisor - A table showing total cases grouped by assigned advisor. Total count, then the count of profitable and not profitable cases should be shown, plus the overall total fees and average fee per case.

Completed cases table - list of all cases that completed during the selected period. These are the cases used to gneerate the above graphs and tables.

By default the report will show the previous weeks data, however this should be configurable. There will be a button to toggle between showing last weeks, last months, or a custom date range worth of data. When changed, the tables and graphs should update to reflect data included in the selected range.

Filter buttons will be provided next to entries in cases by mortgage and cases by advisor. On clicking one of these buttons, the Completed Cases table will be filtered to only show cases matching the filter option clicked (e.g only cases where Joe Bloggs is the advisor, or cases for mortgage type of first time buyer).

The spreadsheet should auto generate when additional data is entered in to the second sheet. It should support adding a years worth of data, and not require any formulas to be adjusted, or selection ranges to be updated.
